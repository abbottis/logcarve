# Workflow reservation — P1

No executable Muse Code workflow is installed. The MVP uses the four project skills and built-in `/plan`, `/grill` and `/taste` with one lead.

After a manual procedure is proven repeatable, author a version-compatible bounded JavaScript workflow and save it at project scope using `muse workflows save`. Keep reviewers read-only and isolate each writer in its own worktree. Restart a trusted session before requesting a newly saved workflow; inspect runs with `/workflows`.

See [the project Muse guide](../../docs/muse-code.md) and [official workflows](https://dev.meta.ai/docs/muse-code/workflows). Hook configuration is also P1 and is not installed by this scaffold.
